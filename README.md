# Desktop updates

Signed desktop update artifacts for Windows 11 x64.

[Latest release](https://github.com/Everplain-Distribution/desktop-updates/releases/latest)

Each release provides a signed update manifest and program archives. Existing installations verify the signature, archive size, SHA-256, and individual program files before activation.

Use the application's update settings for normal updates. An existing portable installation can also use the migration archive supplied with its selected release.
